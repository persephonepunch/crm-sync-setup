1 · Staff: what changes when the VPN goes

How the migration runs

Objections to replacing the VPN

"Our VPN works."
It also gives every connected user the whole network, and VPN appliances are among the most attacked devices on the internet. With per-app access, a stolen password opens one app.
"Our legacy apps won't work."
Anything that speaks TCP or UDP runs over the client and the tunnel, and web apps need no client at all. Pilot the hardest app first.
"It will be slower."
Users connect to the nearest Cloudflare data centre instead of hairpinning through one head office, which matters most for teams spread across a region like APAC.
"What do we show the auditor?"
Every allow and deny is logged per user and per app, which is the evidence SOC 2 access controls (CC6) ask for.

3 · Closed-fee middleware and CRM: where the gaps are

Integration platforms charge to move data between a CRM and commerce systems. They move the record; the consent, retention, erasure and authority around it stay each system's own problem. Under the umbrella, the Python agent and every sync pass one place that carries those rules.

4 · Permissions and rendering: why Auth Me changes SSR

On a Node server, personalising a page usually means rendering it per request (SSR), so nothing can be cached for everyone. With Xano Auth Me returning each caller's roles and capabilities, the page can stay one cached copy (ISR) at the edge, and only the permission answer is per caller. The same answer serves a browser, a Web Component in any framework, and an AI agent through /mcp.

The runtimes line up too. Custom code steps in Xano (Lambdas) run JavaScript or TypeScript on Deno, which uses the same web-standard Request and Response model as Cloudflare Workers. A typical AWS setup runs Node, with its own request objects and packaging. Code written against web standards moves between Xano and the edge with little change; code written for Node usually needs porting.

Node server, SSR per userEdge ISR + Xano Auth Me
Where permissions liveBaked into each rendered pageOne Auth Me answer per caller: roles and capabilities
CachingPersonalised pages cannot be sharedThe page is cached once and served to everyone

Where the check is enforcedIn the render, per frameworkIn the Worker, on every action, for every caller

A VPN trusts the network, and middleware trusts the record. Under the Cloudflare umbrella nothing is trusted by default: the person, the device, the agent and the sync are each checked on every request, against one system of record.
